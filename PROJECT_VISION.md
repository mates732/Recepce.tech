# PROJECT VISION

This document is the source of truth for every product and design decision.

=========================================================
THE WEBSITE IS NOT ABOUT ONE PRODUCT
=========================================================

Recepce.tech is NOT just the website for an AI Receptionist.

It is becoming my personal AI laboratory and digital headquarters.

Think of it as my own ecosystem.

The website should work as a premium personal hub (similar in purpose to a Linktree), but instead of just listing links, it tells the story of everything I build.

Every page, every section and every future feature should reinforce this vision.

=========================================================
WHO I AM
=========================================================

I am not presenting myself as:

- a freelancer
- an agency
- a web designer

I am a builder.

I design, develop and ship intelligent systems.

I combine:

- Software Engineering
- AI
- Automation
- Product Design
- Research
- Building in Public

The website should communicate this immediately.

=========================================================
THE WEBSITE MUST REPRESENT MY COMPLETE ECOSYSTEM
=========================================================

The website should gradually represent everything I build.

Not just AI Receptionist.

The ecosystem currently includes:

1. SOFTWARE DEVELOPMENT
2. AI SYSTEMS
3. CORTEX — my own intelligence engine
4. PRODUCT DESIGN
5. PORTFOLIO
6. CONTENT
7. FITNESS
8. CURRENT FOCUS
9. CONTACT

=========================================================
CORE MESSAGE
=========================================================

The website should answer one question:

"Who is Matyáš?"

Answer:

A builder creating intelligent systems.

=========================================================
IMPLEMENTATION RULE
=========================================================

From now on, every implementation decision must support this vision.

Before creating any new section, component or page, ask yourself:

"Does this strengthen the ecosystem?"

If the answer is no, do not build it.

Never optimize for adding more pages. Optimize for making the ecosystem feel coherent.

=========================================================
DO NOT IMPLEMENT EVERYTHING NOW
=========================================================

This is a long-term vision document.

Use it to guide all future implementation. Do not create placeholder pages just because they are mentioned here. Implement them only when appropriate.
